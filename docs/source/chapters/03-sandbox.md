## 標準のSandboxを有効にしても、通信は止まらない

:::{container} rows
外向き通信
: 既定で許可。GUIのトグルはオン・オフだけで、通信は止まらない

fetch・統合ブラウザ
: サンドボックスの対象外。別のポリシーで止める必要がある

Localセッション
: 対象外。効くのはAgent Hostセッション（Copilot）だけ

環境変数・セッション
: VS Code Serverを共有するため、案件ごとに分けにくい
:::

:::{container} callout
個別の設定で塞げる穴はあるが、封じ込めの全体を案件単位で強制するには足りない
:::
