```{revealjs-notes}
案件によって扱う情報が違い、求められる機密性も違う。ある案件で、AIのWeb検索機能をオフにするよう求められた。理由は、検索クエリで案件情報が外に出ること、OSSライセンス違反、プロンプトインジェクションのリスク。ただ、機能をオフにしてもエージェントはcurlなどでWeb検索に相当することができてしまうので、外部通信禁止と解釈した。組織のポリシーで止めると対象外のメンバまで制限されるので、それも避けたい。だからといってAIを全部やめるのではなく、その案件でも使い続けたい。
```

## 求められたことは2つ

:::{container} eyebrow
01 背景
:::

:::{container} steps
外部通信の遮断
: 公式サーバ（GitHub）以外へ通信しない

案件の分離
: 案件Aの情報を、案件Bの作業に混ぜない

  （ファイル、会話履歴、認証情報）
:::

:::{container} callout
しかも「設定し忘れ」や「AIによる設定の書き換え」で崩れないこと
:::

```{revealjs-notes}
求められたのは外部通信の遮断。もともと社内で一番気にしていたのは、案件間の情報の混在だったので、2つをまとめて満たす構成にした。どちらも、人の設定ミスやエージェントの書き換えで崩れないことが前提。
```

```{revealjs-notes}
エージェントにcurlを実行させると、名前解決の段階で失敗し、エージェント自身が「サンドボックスのポリシーで遮断された」と説明した。続けてPythonでも試してと頼むと、同じ宛先を別の手段で再試行することはできない、と自分から断った。今日はこの状態を、案件ごとに、しかも設定し忘れても崩れない形で作った話。
```
