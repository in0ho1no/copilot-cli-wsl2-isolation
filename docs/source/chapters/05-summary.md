## 「これで保証」ではなく、多層防御の一層

:::{container} eyebrow
05 まとめ
:::

| 残る制約 | 扱い |
| --- | --- |
| 管理設定が、契約形態や更新で効かなくなる可能性 | 構築時に（managed）の表示を確認する |
| Copilot CLIは自動で更新される | 更新後に、同じ手順で再検証する |
| 別ターミナルでの人の操作 | 運用ルールで扱う |
| Windows側からの参照（`\\wsl.localhost`） | 運用ルールで扱う |
| 意図的な迂回（`command copilot`、`wsl -e`） | サンドボックスは外れない。残りは運用ルール |

```{revealjs-notes}
技術で塞げたのは、エージェントが自分で起こす通信と参照。人の操作や意図的な迂回は残るので、運用ルールと組み合わせる前提。CLIの自動更新で挙動が変わる可能性もあるので、検証手順を残しておき、更新後に同じ手順で確かめる。
```
